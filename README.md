# Hostel Room Booking and Fees Management System

## Introduction
A Python-based system developed for 1203 ST – Programming Fundamentals
to manage hostel room allocation and student fee payments.

## Features
- Hostel room and capacity management
- Student registration
- Room allocation
- Room capacity checking
- Full and partial fee payments
- Student search
- Hostel occupancy reports
- Fee defaulter reports
- JSON file persistence
- Menu-driven interface

## Hostel Structure
- Block A: 10 rooms, 4 students per room
- Block B: 8 rooms, 4 students per room
- Block C: 6 rooms, 3 students per room

## Requirements
- Python 3.x
- No external libraries required
